## Sobre o projeto

O projeto realiza requisições assíncronas utilizando Fetch API para buscar informações reais de filmes e renderizar os resultados dinamicamente na página em formato de cards.

## Endpoint Utilizado

endpoint principal:

/movie/popular

Endpoint de pesquisa:

/search/movie
